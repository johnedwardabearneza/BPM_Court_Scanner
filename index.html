Core Capabilities

Engineered for Precision Legal Operations

Every feature is purpose-built to accelerate docket parsing while eliminating manual document hunting and error-prone tracking.

Dual-Court Architecture

Unified interface supporting both New York Supreme Court Appellate Division (AD2) and Kentucky Court of Justice (C-Track) portals in a single client.

Targeted Brief Filter

Identifies collectable briefs (Appellant, Respondent, Reply, Cross-Appeals) while automatically rejecting procedural notices, receipts, and fee confirmations.

Visual Captcha Handoff

When court security triggers a challenge, the browser surfaces cleanly for instant human solving, then seamlessly resumes automated scanning with zero data loss.

Zero Cloud Leaks

Runs strictly locally on Windows with an isolated Microsoft Edge profile. No third-party scraper servers or confidential case telemetry sent to external clouds.

Audit-Ready Excel Reports

Compiles full monthly tracking spreadsheets (.xlsx) with formula validations, standard SOP file naming, and verification audit trails.

Remote Service Guard

Silent background heartbeat for non-disruptive update alerts, scheduled maintenance announcements, and system integrity safeguards.

Dual-Jurisdiction Architecture

Engineered to handle the unique filing formats, docket conventions, and document classification requirements of both New York and Kentucky appellate court systems.

New York — AD2

NYSCEF

Automates the ingestion of weekly Handdown Motion Lists from the New York State Supreme Court Appellate Division, Second Department (AD2), followed by targeted document lookups in NYSCEF.

  • Direct calendar scraping from official AD2 Handdowns portal (ad2/handdowns.shtml)
  • Appellate Division County Index resolution (County Code 96)
  • Smart classifier: Captures Appellant, Respondent & Reply Briefs while ignoring procedural receipts
  • Real-time Captcha detection with visual browser handoff & auto-resume

Kentucky — C-Track

Audit Ready

Navigates the Kentucky Court of Justice Appellate Public Portal (C-Track), querying monthly briefing schedules and downloading collectible briefs across the entire state docket.

  • Automated monthly briefing searches with pagination and docket traversal
  • Standard Operating Procedure (SOP) filename formatting: CaseNo_DocDescription.pdf
  • Generates complete Excel workbooks (.xlsx) with formula totals & case count validation
  • Multi-lot & document deduplication guard against duplicate records
Step-by-Step Tutorial

How to Use BPM Court Scanner

No technical background required. Follow this quick tutorial to start extracting briefs and generating reports in minutes.

1

Select Date

Open the app. By default, it selects today's date. Or click Today / pick any specific handdown calendar date from the calendar dropdown.

2

Start Scanning

Click the green Start Scanning NY button. The app will launch an automated Microsoft Edge instance and parse the day's motion list.

3

Captcha Handoff

If NYSCEF displays a Cloudflare check, Edge automatically pops up into view. Solve the checkmark in Edge, then click Done / Continue in the app.

4

Review Output

PDF briefs are automatically saved to your downloads/NY_YYYY-MM-DD/ folder with organized case folders and clean filenames.

1

Switch Tab

Click the Kentucky (C-Track) button at the top of the window to switch into the Kentucky appellate workspace.

2

Choose Month

Select the desired Month and Year from the selectors (e.g. November 2026) to query the official briefing schedule.

3

Run Full Scan

Click Start Full Scan. The background worker queries C-Track dockets, skips irrelevant court orders, and downloads collectible briefs.

4

Open Excel

A comprehensive Excel audit file (Kentucky_Briefs_Audit_YYYY-MM.xlsx) is instantly created in the output/ directory.
